Thao tác nhanh

Mở tất cả tài khoản: chỉ mở đúng số profile hiện có (không tạo tab trống).
Mở tab: mở đúng số tab nhập ở Cấu hình; nếu ít profile hơn, phần dư là tab trống.
Tên profile sẽ hiển thị ngay trên tab trình duyệt để dễ nhận biết.

Tài khoản / Profile

    Trạng thái cửa sổ (0)

    Lưới cửa sổ

    Kích thước cửa sổ

    Để 0 = tự động chia đều màn hình theo lưới.

    Antidetect / Fingerprint

    Mỗi cửa sổ mới được sinh fingerprint riêng (UA, WebGL, canvas, screen…). Bạn có thể ghi đè UA theo từng tài khoản ở tab Trang chủ.
